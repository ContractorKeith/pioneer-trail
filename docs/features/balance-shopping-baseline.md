# Shopping-only reference baseline

Seeds 0–9999 per scenario; Oregon; normal difficulty. Eight occupations use 1848; Soldier uses 1866. These 450,000 runs used the pre-survival reference policy (simulation integrated at 3380da2): it bought supplies and treated illness but never hunted, fished, or foraged. Poor-party failure rates therefore measure this policy, not an optimal player or occupation viability.
