# Minigames

Hunting uses a top-down 80×23 field: arrows or vim keys move a crosshair, so targets and aim stay legible at the minimum terminal size. A side-view prototype would give prettier silhouettes but compresses vertical aim into a single trail line and makes animal overlap ambiguous. Rafting is likewise top-down downstream motion; both worlds advance at one fixed 30fps tick and remain deterministic from their run seed.
