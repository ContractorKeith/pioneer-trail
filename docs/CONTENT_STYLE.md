# Content style guide

Voice for all in-game text (events, quotes, shopkeeper, epitaphs):

- Plain 1840s frontier prose. Short sentences. No modern slang, no anachronisms.
- Second person, present tense for events: "A wheel splinters on the rocks."
- Talk-to-people quotes are first person from a named emigrant, one to three sentences.
- Never copy text, epitaphs, or art from any Oregon Trail release. Write it fresh.
- Native peoples are named by nation (Shoshone, Pawnee, Cayuse) and written as people, not hazards.
- Death messages are blunt, not jokey: "Sarah has died of cholera."
- Keep one event to one screen: 3 lines of text max before choices.
